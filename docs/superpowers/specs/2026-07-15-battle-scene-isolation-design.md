# 战场独立画面设计

## 目标

战斗开始后，只保留战场本身。大地图的城名、部队人数和底部操作按钮暂时隐藏；战斗结束后恢复。

## 方案

1. 城名与部队人数各增加“显示/隐藏”入口。
2. 回合、外交、间谍和存档按钮在进入战斗时隐藏。
3. `MapScene` 在启动 `BattleScene` 前隐藏上述地图界面。
4. `BattleScene` 结束后唤醒 `MapScene`，由 `MapScene` 恢复地图界面。

## 边界

- 不删除地图对象，不重新加载存档。
- 不改变战斗规则、城市数据或部队数据。
- 战斗结果仍沿用已有的回传流程。

## 验证

1. 进入战斗时截图确认没有城名、部队数字与地图按钮。
2. 结束战斗后确认地图按钮与标签恢复。
3. 运行全部自动检查和打包。
