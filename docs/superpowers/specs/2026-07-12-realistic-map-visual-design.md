# 唐末五代大地图写实厚重美化方案

## 目标

将大地图改为写实、厚重且适合手机操作的唐末五代战略地图。美化只改变视觉呈现，不改变城池、行军、外交或战斗规则。

## 视觉方向

- 地貌使用深绿平原、黄土高地、灰岩山脉三类主色。
- 山脉有明确的明暗和高度感；河流有浅滩与岸线，不使用抽象色块。
- 城池呈现唐末城墙、城门和地域化建筑，并保持二十座城池可一眼区分。
- 行军部队使用小旗、甲胄和队列轮廓，移动时有克制的旗帜与尘土动效。

## 手机显示

- 所有设备始终显示山河、城池、军旗与部队等核心细节。
- 仅简化肉眼不明显但耗电较高的动态效果，例如粒子数量和烟尘层数；不得删减核心画面内容。
- 横屏和竖屏下，地图操作与右下角按钮均不得互相遮挡。

## 实现边界

- 地图底图、城池标记、部队标记分为独立绘制部分，便于单独调整。
- 保留现有点击城池、点击部队、拖动与缩放操作。
- 使用可重复生成的位图纹理和程序绘制细节，避免依赖外部在线资源。

## 验收标准

1. 二十座城池在默认视野下可清楚辨认并可点击。
2. 山、河、平原具有明显层次，整体呈现厚重的唐末战争氛围。
3. 部队静止与移动状态均有清楚身份和方向提示。
4. 手机横竖屏的地图、城池和主要按钮不重叠。
